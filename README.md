# Programación para Inteligencia Artificial

Repositorio de materiales para la asignatura **Programación para Inteligencia
Artificial** de la Maestría en Inteligencia Artificial.

## Organización

Los materiales se agrupan por unidad y semana. Cada carpeta contiene su propia
guía, recursos y, según el propósito de la sesión, notebooks o proyectos de
Python completos.

```text
unidad-01-python-moderno/
├── semana-01-curso-acelerado-python/
├── semana-02-tipado-pydantic/
├── semana-03-iteradores-contextos/
└── semana-04-reproducibilidad/
```

## Modalidades de trabajo

- Las primeras semanas pueden utilizar notebooks ejecutables en Google Colab.
- Los archivos `.ipynb` también se versionan en este repositorio.
- Los proyectos completos de Python administran sus dependencias de manera
  independiente con `uv`.
- La raíz del repositorio funciona como guía del curso y no constituye un proyecto de Python.

## Versión de Python

El curso requiere Python 3.12 o posterior aunque se recomienda Python 3.13.

## Unidad 1

La primera unidad introduce Python moderno en cuatro sesiones: fundamentos del
lenguaje, tipado y modelos de datos, flujos perezosos y manejo de recursos, y
reproducibilidad de proyectos.

Consulta el [recorrido de la unidad 1](./unidad-01-python-moderno/README.md) y la
[guía de la semana 1](./unidad-01-python-moderno/semana-01-curso-acelerado-python/README.md).
