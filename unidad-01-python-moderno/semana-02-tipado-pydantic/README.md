# Semana 2: Tipado, Pydantic y modelos de datos

Sesión dedicada a expresar contratos de datos claros y validar información en
los límites de una aplicación.

- Modelos de datos con Pydantic.
- Validación, serialización y mensajes de error.
- Aplicación a entradas y salidas de sistemas de IA.
