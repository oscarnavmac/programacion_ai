# Unidad 1: Python moderno para IA

Esta unidad establece una base común de Python y presenta prácticas modernas
para construir software de inteligencia artificial legible y reproducible.

## Recorrido

1. **[Curso acelerado y Zen de Python](./semana-01-curso-acelerado-python/README.md):**
   dos notebooks, en ese orden. La primera incluye sintaxis, funciones, colecciones,
   control de flujo, excepciones, módulos, orientación a objetos y 14 ejercicios.
   La segunda desarrolla las 19 reglas del Zen con ejemplos y un reto de refactorización.
2. **Tipado, Pydantic y modelos de datos:** contratos explícitos y validación de
   entradas y salidas.
3. **Iteradores, generadores y context managers:** procesamiento perezoso y
   manejo seguro de recursos.
4. **Reproducibilidad:** transición de notebook a proyecto Python con `uv`,
   Ruff y pytest.

Cada carpeta semanal contiene la guía y los materiales correspondientes a la
sesión.

## Trabajo con las notebooks de la semana 1

La [guía de la semana 1](./semana-01-curso-acelerado-python/README.md) incluye los
botones para abrir ambas notebooks en Google Colab y sus archivos en el repositorio.
Solo requieren la biblioteca estándar; también puedes usar Python 3.12 o posterior
con un entorno de notebooks local.

Las explicaciones están en español. El código puede estar en español en la primera
notebook y está en inglés desde la segunda. Las soluciones se consultan en bloques
Markdown y se copian a una celda de código para probarlas; no se ejecutan con
**Ejecutar todo**. Las funciones de apoyo necesarias para continuar el taller
permanecen como código ejecutable.
