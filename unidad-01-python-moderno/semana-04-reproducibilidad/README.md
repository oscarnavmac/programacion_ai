# Semana 4: Reproducibilidad con uv, Ruff y pytest

Esta semana utilizará un proyecto Python completo en lugar de una notebook. El
proyecto se inicializará dentro de esta carpeta cuando se diseñe la sesión.

## Temas previstos

- Estructura de un proyecto Python.
- Gestión de Python y dependencias con `uv`.
- Configuración mediante `pyproject.toml`.
- Entornos reproducibles y archivo de bloqueo.
- Formato y análisis estático con Ruff.
- Pruebas automatizadas con pytest.

La comparación entre el flujo interactivo de una notebook y la ejecución de
módulos y scripts formará parte de esta sesión.
